# **App Name**: TimeWise Attendance

## Core Features:

- User Authentication: Implement login functionality for admin and worker roles using hardcoded credentials stored in local storage.
- Daily Check-In: Enable workers to check in once per day, recording the timestamp in local storage. Prevent multiple check-ins on the same day.
- Admin Record Management: Admin can view, mark as paid, and delete attendance records, all managed within local storage.

## Style Guidelines:

- Primary color: A calm blue (#3498db) for the header and main sections.
- Secondary color: Light gray (#f2f2f2) for backgrounds and card containers.
- Accent: Green (#2ecc71) to indicate 'Mark as Paid' actions.
- Use a responsive layout that adapts to different screen sizes.
- Use clear and recognizable icons for actions like 'Check In', 'Mark as Paid', and 'Delete'.
